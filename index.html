Spyne Bulk Media Downloader

Upload a CSV with media IDs and credentials, paste your auth token, hit Download. All VINs are bundled into one master ZIP or saved to a folder you choose.

1. Authorization token

Open console.spyne.ai, log in, then open DevTools → Network tab. Trigger any action, click any request, copy the authorization header value. Saved locally in your browser; expires every 5–6 days.

2. Media IDs (CSV upload)

CSV must include (case-insensitive): Media ID, Enterprise ID, Team ID.
Optional: User ID, VIN / Sku Name for labels.

Download a sample CSV

3. Download destination

The proxy URL (Option A) is required to fetch blobs — Spyne's S3 URLs block direct browser requests (CORS). Set the proxy URL, then optionally also choose a folder (Option B) to save files there instead of a master ZIP. If neither is set, each VIN opens in a new browser tab.

Required Cloudflare Worker proxy — needed to fetch blobs (bypasses S3 CORS restriction)

Deploy proxy/worker.js to Cloudflare Workers (free tier, ~2 min). Paste the deployed URL above. See README for step-by-step instructions.

— and optionally —
Option B Folder picker — save each VIN directly to a folder instead of a master ZIP

Set the proxy URL above first, then choose a folder. Files will be saved as enterpriseId/teamId/VIN/ inside your chosen folder.

⚠ Your browser does not support the folder picker (requires Chrome 86+ or Edge 86+).
