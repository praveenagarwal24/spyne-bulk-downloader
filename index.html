Spyne Bulk Media Downloader

Upload a CSV with media IDs and credentials, paste your auth token, hit Download. All VINs are bundled into one ZIP. Calls api.spyne.ai/medias/bulk-download directly from your browser.

1. Authorization token

Open console.spyne.ai, log in, then open DevTools → Network tab. Trigger any action, click any request, copy the authorization header value. Saved locally in your browser; expires every 5–6 days.

2. Media IDs (CSV upload)

CSV must include these columns (case-insensitive): Media ID, Enterprise ID, Team ID.
Optional columns: User ID, VIN / Sku Name for labels.
Each Media ID must be a real 24-character Spyne ObjectId (e.g. 69f53edf315b2a8070388552). Grab them from console.spyne.ai DevTools → Network tab.
